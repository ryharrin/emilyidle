# Milestone v3.1: Career Depth & Landing

**Status:** ✅ SHIPPED 2026-02-01
**Phases:** 32-36
**Total Plans:** 13

## Overview

Make Career the default landing surface for fresh saves and deepen the career progression into clear stages with lasting, meaningful choices and strong progress feedback.

## Guiding Constraints

- Cash remains career-driven (salary + sessions); watch ownership is not a cash faucet.
- Selectors/actions stay pure (no time reads inside selectors/actions).
- Keep UI selectors stable (`id`, `data-testid`).

## Milestone Summary

**Decimal phases:** None

**Key Decisions:**
- Allow pre-track therapist sessions via selector-only fallback policy until track unlock, preserving the meaningful level-3 track choice.
- Treat deep links as non-persistent navigation so existing saves keep last-tab behavior.

**Issues Resolved:**
- Fresh-save landing defaults to Career and stays predictable for existing saves.
- Career sessions no longer show as unavailable immediately after starting Career (pre-track window supported).
- Quartz set-time mini-game dial/hand alignment regression fixed (desktop + mobile).

- None blocking v3.1 completion.

**Technical Debt Incurred / Follow-ups:**
