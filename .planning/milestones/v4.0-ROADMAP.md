# Milestone v4.0: Watch Interactions & Catalog Polish

**Status:** ✅ SHIPPED 2026-02-05

**Total Plans:** 16

## Overview

Milestone v4.0 deepens watch interactions with new and expanded mini-games, surfaces per-watch stats for clearer decisions, expands catalog variety across progression tiers, and wraps the experience in a mobile-first polish.

**Plans**: 3 plans

## Milestone Summary

**Decimal Phases:** None

**Key Decisions:**
- Isolate `HelpModal` within a dedicated `#app-shell` so the background can be inerted and focus can be restored cleanly after closing (Phase 47)
- Intercept Tab/Shift+Tab between the help search input and close button instead of relying on WebKit focus quirks (Phase 47)
- Preserve WebKit-friendly sticky navigation by aligning `.page-nav` to the grid start before relying on `position: sticky` (Phase 47)
- Allow catalog titles to wrap tier badges safely by forcing `flex-wrap` and shrink-aware flex children (Phase 47)
- Keep catalog tier badges and per-watch stats in sync via shared CSS variables and metadata (Phases 45/47)
- Expand catalog variety with tier-aware metadata and new assets for low/mid/lux tiers (Phase 46)

**Issues Resolved:**
- Resolved the catalog tier badge overlap by adding flex-wrapping headers and shrink-aware badge styling
- Fixed the mobile tab bar sticky behavior so it remains accessible while scrolling
- Stabilized the HelpModal focus trap on WebKit mobile using inert shells and manual Tab capture

**Issues Deferred:**
- No new issues deferred; the milestone mechanisms completed the planned mobile polish items

**Technical Debt Incurred:**
- Need a dedicated Playwright scenario for therapist session cash/enjoyment deltas and cooldown UX (not covered in v4.0)
