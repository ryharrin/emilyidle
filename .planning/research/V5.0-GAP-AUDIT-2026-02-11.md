Primary files:

- `src/App.tsx`

- Keep collapsed filters as the baseline behavior contract and tighten mobile affordance tests.
- Split "actionable" versus "affordable" semantics so unowned affordable cards have a distinct visual treatment from owned quick-action cards.
- Re-run readiness-scan UX checks to ensure tab badges + mission cues do not over-noise the first viewport.

Primary files:
- `src/ui/tabs/CatalogTab.tsx`
- `src/style.css`
- `src/ui/navigation/PageTabRail.tsx`
- `tests/touch-targets.spec.ts`
- `tests/collection-loop.spec.ts`

### Phase 59 (Data depth + media/tier contracts)
- Add explicit validation for movement inference confidence/fallback paths (not just happy-path movement metadata).
- Keep media/base-path tests green and add targeted checks only if URL resolution logic changes.
- Ensure richer detail content remains in secondary surfaces (details sheet/compare) without first-viewport clutter regression.

Primary files:
- `src/game/catalog.ts`
- `src/game/data/watchModels.ts`
- `tests/catalog-image-url-contract.unit.test.ts`
- `tests/catalog-image-rendering.spec.ts`

### Phase 60 (Guardrails + maintainability)
- Execute `DEBT-01` as real file-boundary splits instead of incremental in-file growth:
  - App shell orchestration extraction from `src/App.tsx`
  - Catalog card/render pipeline extraction from `src/ui/tabs/CatalogTab.tsx`
  - Selector-domain submodule extraction from `src/game/selectors/index.ts`
  - Catalog/career/nav style blocks extraction from `src/style.css`
- Add focused regression tests tied to each extraction boundary.

1. **False "planned" signals in notes** can cause duplicate work and churn.
