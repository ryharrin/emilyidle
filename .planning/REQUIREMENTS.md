# Milestone v4.0 Requirements: Watch Interactions & Catalog Polish

## Overview

Deepen the watch interaction experience with improved mini-games and catalog polish. This milestone focuses on making watch interactions more engaging and rewarding while expanding the catalog variety and improving the mobile experience.

**Milestone Goal:** Enhanced watch mini-games with visual polish, catalog expansion with more variety, and improved mobile UX.

---

## v1 Requirements (This Milestone)

### Watch Interactions

- [ ] **WATCH-01**: Winding mini-game has more interactive control with visual winding animation
- [ ] **WATCH-02**: Setting time mini-game for quartz watches with interactive controls
- [ ] **WATCH-03**: Setting date mini-game for appropriate watch movements
- [ ] **WATCH-04**: Strap changing mini-game with visual feedback
- [ ] **WATCH-05**: All mini-games have clear success/failure states with visual feedback
- [ ] **WATCH-06**: Mini-game rewards scale appropriately with watch tier and precision

### Catalog Expansion

- [ ] **CAT-05**: Add low-end watch brands and models (accessible early game)
- [ ] **CAT-06**: Add mid-tier watch brands and models (mid-game progression)
- [ ] **CAT-07**: Add luxury/high-end watch brands and models (late-game goals)
- [ ] **CAT-08**: Watch variety spans from affordable to luxury price points
- [ ] **CAT-09**: New watches have appropriate enjoyment/cash rates for their tier
- [ ] **CAT-10**: All new watches have proper catalog images and metadata

### Individual Watch Stats

- [ ] **STATS-01**: Catalog shows individual watch enjoyment rate per watch
- [ ] **STATS-02**: Catalog shows individual watch cash rate per watch
- [ ] **STATS-03**: Stats vary meaningfully between watches (not uniform within tier)
- [ ] **STATS-04**: Collection view shows equipped watch's contribution breakdown
- [ ] **STATS-05**: Stats are visible without needing to purchase the watch

### Mobile Experience & UI Polish

- [ ] **MOBILE-01**: Tab navigation uses horizontal scroll with snap behavior
- [ ] **MOBILE-02**: Tab bar remains sticky during scroll
- [ ] **MOBILE-03**: Settings panel has restyled fieldsets and checkbox groups
- [ ] **MOBILE-04**: Collection/Catalog uses section grouping with in-page subnav
- [ ] **MOBILE-05**: Help modal includes search functionality
- [ ] **MOBILE-06**: Help modal has sticky header and improved chip layout
- [ ] **MOBILE-07**: Interaction modals have larger touch targets
- [ ] **MOBILE-08**: Stats breakdown groups modifiers and shows subtotals
- [ ] **MOBILE-09**: All touch targets meet minimum 44px accessibility standard

---

## Future Requirements (Deferred)

### v4.1+ Potential Features

- Additional watch complications (chronograph, moon phase, etc.)
- Watch servicing/repair mini-games
- Watch trading/selling mechanics
- Collection showcase/sharing features
- Seasonal/limited edition watches
- Achievement system for interactions

---

## Out of Scope

- **Multiplayer features** — This is a single-player idle game experience
- **Real-time multiplayer trading** — Async trading only if implemented
- **3D watch models** — 2D images with animations only
- **Video cutscenes** — Static images and CSS animations only
- **Haptic feedback** — Standard visual/audio feedback only
- **PWA/offline mode** — Web-only for this milestone
