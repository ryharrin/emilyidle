  <action>
Convert winding progress to be driven by pointer drag instead of elapsed time.

Guidelines:
- Keep helpers pure in `windingMath.ts` (input: deltas + prior snapshot; output: progress/tension/velocity/band).
- Implement Pointer Events handlers with `setPointerCapture(pointerId)` on pointerdown.
- Handle `pointercancel` the same as `pointerup`.
- Add local CSS for the drag surface: `touch-action: none` (scope to the crown/drag surface, not the whole document).

State machine (suggested):
- idle -> dragging -> resolved
- While dragging, update:
  - `progress01` and `tension01` based on cumulative drag distance or angular delta
  - `velocity01` based on recent delta smoothing
  - `band` derived from progress thresholds
- On pointer up/cancel, freeze state and compute outcome tier (reuse existing band thresholds if still appropriate).

Do not introduce new dependencies.
