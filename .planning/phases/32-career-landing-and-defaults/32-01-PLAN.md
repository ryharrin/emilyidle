  <action>
- Create `src/ui/navigation/landing.ts` exporting:
  - `export type TabId = "collection" | "career" | "upgrades" | "workshop" | "maison" | "nostalgia" | "stats" | "save" | "catalog";`
  - `export type TabActivationSource = "deep-link" | "system";`
  - `export type NavigationState = { lastTabId: TabId };`
  - `export function resolveTabAlias(value: string): TabId | null`:
    - Map `"catalog"` -> `"collection"` (preserve existing deep links).
    - Return the id if it matches a TabId, else null.
  - `export function resolveLandingTab(args)` returning `{ tabId: TabId; source: TabActivationSource }`.

- `resolveLandingTab` MUST implement the concrete policy from Phase 32 context:
  1) If `args.search` contains a valid + visible `tab` param, return it with `source: "deep-link"`.
  2) Else if `args.hasSave === true` and `args.navigationState?.lastTabId` is visible, return it with `source: "system"`.
  3) Else if `args.hasSave === false`, return `"career"` when visible; otherwise return `"collection"`.
  4) Else return `"collection"`.

- The resolver MUST be pure and environment-agnostic:
  - No `window`, no `document`, no localStorage reads.
  - Visibility MUST be provided via an injected `isVisible(tabId)` callback.
  </action>

- Resolver exists and is purely driven by function inputs (no browser globals).
