 - Refactor catalog cards to support an inline expandable details area (no modal):
   - Use `<details>`/`<summary>` or an equivalent accessible toggle.
   - Keep the default (collapsed) card view scannable with the action bar clearly visible.
   - Expanded content MUST be descriptive-only:
     - Show the entry description (`entry.description`).
     - Show a compact specs list with 4-5 items (pick from: Year, Tags, License, Author, Source).
     - Do NOT include purchase/gate info in the expandable section (price/owned/CTA stay in the action bar).
   - Remember expand/collapse state per card for the duration of the session:
     - Store open/closed in React state keyed by `entry.id`.
     - The expanded state should survive re-renders caused by filtering, sorting, or buying.
 - Purchase micro-feedback:
   - When a purchase occurs from a catalog card, apply a brief highlight to that card (e.g., a CSS class) and clear after ~600-900ms.
   - Respect `prefers-reduced-motion: reduce` (disable the animation).
 - Maintain medium-density grid: mobile 1 column; desktop 2-3 columns.
  </action>
