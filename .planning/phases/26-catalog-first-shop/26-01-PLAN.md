<task type="auto">
  <name>Task 1: Make Catalog visible and implement landing tab resolution (deep link -> first-run -> last tab)</name>
  <files>
src/App.tsx
  </files>
  <action>
 - Update tab visibility so the Catalog tab is available from the beginning (fresh save).
   - In `tabVisibility`, make `catalog: true` (Catalog is not gated for Phase 26).

 - Add persisted last-tab navigation state:
   - Add a new localStorage key `emily-idle:navigation` (separate from `emily-idle:settings`).
   - Store JSON shape: `{ "lastTabId": TabId }`.
   - Provide a tiny runtime validator when reading (unknown/malformed -> ignore).

 - Implement initial landing tab resolution with the locked override order:
   1) Deep link override:
      - Use a query param `tab` (e.g. `/?tab=save`, `/?tab=collection`, `/?tab=catalog`).
      - Validate the value against known `TabId`s and only select it if that tab is visible.
      - If invalid or hidden, ignore and continue resolution.
      - IMPORTANT: selecting a tab via deep link must NOT update `emily-idle:navigation`.
   2) Fresh save first-session override:
      - Treat "fresh save" as `window.localStorage.getItem("emily-idle:save") === null`.
      - Only on this first session (no save AND no existing `emily-idle:navigation`), force `activeTab` to `catalog`.
   3) Existing save behavior:
      - If `emily-idle:navigation.lastTabId` exists and is visible, use it.
   4) Fallback:
      - Fall back to `catalog` (and if Catalog is hidden by user settings, fall back to `collection`).

 - Ensure deep links do not update the persisted last-tab preference:
   - Separate "tab activation source" for tab changes: "user" vs "deep-link" vs "system".
   - Persist lastTabId only for "user" activations (click or keyboard activation of a primary nav tab).

 - Update the "active tab became hidden" safety effect:
   - Prefer `catalog` when visible; otherwise fall back to `collection`.

 - Do NOT add a routing library.
  </action>
  <verify>
pnpm run typecheck
  </verify>
  <done>
 - Fresh saves can see the Catalog tab.
 - Fresh save first session lands on `catalog` by default.
 - Existing saves restore the last visited tab from `emily-idle:navigation` when visible.
 - With `/?tab=...`, the requested tab is selected when visible.
 - Visiting a deep link does not overwrite the persisted last-tab preference.
  </done>
