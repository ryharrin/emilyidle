- In `createStateFromSave(saved)` implement a legacy compatibility path:
  - Detect a "tier-only" save: `saved.watchModels` is missing OR present but effectively empty (no valid entries after sanitization).
  - If tier-only AND `saved.items` has watch tier counts (>0), migrate those counts into `watchModels` deterministically.
- Migration strategy (deterministic, minimal, no RNG):
  - Build a tier->defaultModelId mapping from `WATCH_MODELS`:
    - For each tierId, pick exactly one model id to receive migrated ownership.
    - Use the first model encountered in `WATCH_MODELS` for that tier (array order is deterministic), or explicitly sort by `(brand, referenceNumber, id)` if you want stronger determinism.
  - For each watch tier id (starter/classic/chronograph/tourbillon):
    - Read the sanitized tier count from `items[tierId]` (already parsed from `saved.items`).
    - If count > 0 and a default model id exists for that tier, set `watchModels[defaultModelId] = count`.
- Keep `items` unchanged (do not zero it out); Phase 25 uses `items` for various existing systems and buyWatchModel keeps them in sync going forward.
- Keep existing sanitation rules: model ids must exist in WATCH_MODELS; values must be finite integers >= 0.
</action>
