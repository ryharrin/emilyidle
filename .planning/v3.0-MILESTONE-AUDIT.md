## Cross-Phase Integration

Integration checker result: gaps_found.

Critical integration gaps:

- Cash accrual is disconnected from upgrade/income multipliers:
  - `src/game/selectors/index.ts#getRawIncomeRateCentsPerSec` composes BASE + item income + upgrade/set/collection/workshop/maison/catalog-tier/ability/crafted multipliers.
  - `src/game/selectors/index.ts#getTotalCashRateCentsPerSec` returns `getTherapistCashRateCentsPerSec` only.
  - `src/game/sim.ts` accrues `currencyCents` using `getTotalCashRateCentsPerSec`.
  - Result: upgrade systems that describe cash multipliers do not change cash/sec or cash earned.

- Event multiplier naming/behavior mismatch:
  - `src/game/selectors/index.ts#getEventIncomeMultiplier` is an income multiplier.
  - `src/game/sim.ts` applies this multiplier to enjoyment accrual, not cash accrual.
  - If events are intended to affect enjoyment only, this should be renamed/reframed. If intended to affect income, cash accrual needs wiring.
