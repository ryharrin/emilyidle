## Cross-Phase Integration

Integration checker result: passed.

Verified wiring highlights:

- Events multiply both enjoyment accrual and cash accrual in the sim tick (`src/game/sim.ts`).
- Dollars/sec display matches accrual under events (header stats + Stats cash breakdown use the same effective cash rate).
- Cash remains career-salary driven (no watch-ownership cash faucet; upgrades do not increase dollars/sec).
- Upgrades affect non-cash progression by increasing enjoyment/sec; upgrade previews reflect event-adjusted rates.

## Tech Debt / At-Risk Items

- Interactions are tracked per tier item id (not per model). This is coherent with existing tier-based interaction UI, but becomes more noticeable in a model-first Vault.
- Rates help copy still references a vault softcap reducing dollars/sec; this is now potentially confusing because dollars/sec is career-salary driven.
